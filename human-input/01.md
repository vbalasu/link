I want to build a URL shortening utility. 

It should take the following inputs: 
1. Target URL
2. User-friendly slug

It should output a URL of the following form: 
https://link.{YOUR_DOMAIN}/slug

The user should be able to distribute this URL with their audience. 
Anytime the link is clicked, it should record a timestamp And any other available details about the click

This should be implemented as a cloud service and should support a custom domain. 

There should be a CLI that helps you to:
1. Create the URLs
2. Analyze the access history of the URLs

Choose between AWS and Google Cloud. 

Make sure that this does not incur cost when not in use. Use serverless technologies wherever possible. 

Initial setup for a new domain should be as simple as possible. Use the config.yaml and/or CLI.
